 Even and Odd Number Checker

 Description
A simple Python program to check whether a number is even or odd using a function and the modulus operator.

Technologies
- Python 3

 How to Run
bash
python even_odd_checker.py

 Sample Output
Enter an integer: 8
Result: Even Number

Concepts Used
- Functions
- If-else statements
- Modulus operator (%)
- Exception handling
